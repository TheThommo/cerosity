# FLO Intelligence Architecture

FLO (pronounced "Flow") is Cerosity's AI mental performance coach. This document is the
single reference for where FLO's intelligence lives. Read it before touching anything that
affects FLO behaviour, in text or voice.

## The one rule

FLO has ONE brain: Cerosity. Every reply FLO gives, in any channel, is generated by the
Cerosity server using `buildFloPrompt()` (persona + Red2Blue methodology + brain docs) and
Gemini for inference. Nothing else defines how FLO coaches.

## Layers

| Layer | Responsibility |
|-------|----------------|
| Cerosity server | ALL coaching: persona, Red2Blue, brain docs, athlete context, landing 6-message gate |
| Gemini (`GEMINI_API_KEY`, `GEMINI_MODEL`) | LLM inference - the sole model for FLO replies |
| `server/flo-prompt.ts` | Single source of truth for persona, methodology, voice rules, landing rules |
| `flo_brain_documents` (Supabase) | Document repository, uploaded via HQ `/api/hq/flo-brain` |
| VAPI | STT (Deepgram) + TTS (ElevenLabs) + call UX ONLY - no hosted LLM for coaching |

## How each channel reaches the brain

- Text (landing preview): `POST /api/landing-chat` -> `buildFloPrompt({ forLanding, forChatApi })` -> `getCoachingResponse()` (Gemini).
- Text (authenticated): `POST /api/chat` -> `buildFloPrompt({ forChatApi })` -> `getCoachingResponse()` (Gemini).
- Voice: VAPI assistant (provider `custom-llm`) -> `POST /api/vapi/chat/completions` -> `buildFloPrompt({ forVoice })` -> `getCoachingResponse()` (Gemini).

All three call the same `buildFloPrompt()` + the same Gemini path. Voice differs only in the
prompt tail: `forVoice` adds spoken-mode rules and returns plain spoken text instead of JSON.

## Forbidden (this is what "dual intelligence" looks like)

- OpenAI (GPT 4.1 / gpt-4o) on VAPI for FLO coaching.
- Anthropic (Claude) on VAPI for FLO coaching.
- Any coaching system prompt living in the VAPI dashboard, in `client/.../flo-voice-ptt.tsx`,
  or in `server/vapi.ts`.
- "Syncing" a prompt between the VAPI dashboard and `flo-prompt.ts`. Two copies of a prompt is
  still two brains, even if they currently match.

If you need to change FLO's persona, methodology, or voice behaviour, edit
`server/flo-prompt.ts`. That is the only place.

## Enforcement

`reconcileFloVapiAssistant()` (in `server/vapi.ts`) runs on production startup and PATCHes the
live VAPI assistant onto the `custom-llm` config that points back at Cerosity. Any drift back to
a hosted model or a dashboard prompt is overwritten on the next deploy. See
`docs/FLO_VOICE_SYNC.md` for the voice wiring and verification steps.
